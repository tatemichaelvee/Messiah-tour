# Messiah Tour Music Room

Private practice site for the Messiah Tour Canada 2026 BVs and band: song library, synced stem mixer, guide tracks, charts, BV notes and lyrics.

- Hosted on GitHub Pages.
- Songs, files and the band list live in Supabase (project "Messiah Tour"), locked to emails on the band list.
- Only public connection details are in this repo (`config.js`); the publishable key is safe to share because every table and the music bucket are protected by row-level security.
